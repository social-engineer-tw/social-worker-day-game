# 社工的一日 當所有事情都很重要

正式競賽版：https://social-engineer-tw.github.io/social-worker-day-game/competition-2026/

《社工的一日：當所有事情都很重要》是以臺灣社會工作實務為基礎的互動公共教育遊戲，也是 2026 佛光大學三好 AI 創新應用競賽社會組 AI 數位應用實作類的準備版本。

玩家保留原版的移動、接件與同色工作區交付玩法，同時需要處理會改變後續狀態的專業判斷事件，以及有限、可能延遲的團隊與制度支援。結算呈現完成與未處理工作、決策、支援與制度條件，不以單一分數判定社工是否專業或稱職。

## 核心玩法

- 三關任務地圖：行政紀錄、需求服務、安全確認與網絡協作。
- 專業決策：每關一個情境，選項會改變狀態與後續任務，不以答對或答錯計分。
- 團隊支援：督導、同事、外部網絡及重新排程，共享有限額度；部分支援延遲到位。
- 教育性結算：跨關整理任務類型、重要決策、支援使用、未處理需求與制度限制。
- 隱私與倫理：所有情境均為虛構，不輸入或儲存真實個案資料。

## 操作方式

桌機：

- WASD 或方向鍵移動。
- Q 或 Tab 切換手上任務的目的地提示。
- 碰到任務卡會自動接取，進入同色工作區會自動交付。
- 點擊右側按鈕使用有限支援。

手機或平板：

- 將裝置轉為橫向。
- 以單指在地圖上拖曳角色。
- 決策事件與支援按鈕可直接點選。

## 本機執行

本專案為純前端 HTML、CSS 與 JavaScript，無需安裝套件。直接開啟 `index.html`，或使用任一靜態檔案伺服器即可。

## 測試

```powershell
node --test tests\game-core.test.js
node tests\browser-e2e.js
```

第一組為 8 項核心邏輯測試。第二組會啟動獨立的無頭 Chrome，驗證 22 個操作與狀態，並輸出桌機、決策、結算、觸控直向提示與橫向遊戲畫面至 `test-results/`。

## AI 使用揭露

本次改造使用 OpenAI Codex 生成式 AI 程式開發助理協助檢查既有程式、實作 HTML、CSS 與 JavaScript、建立自動化測試，以及整理投稿文件草稿。開發者提供社工專業與倫理限制、決定功能與文案、執行測試並負責最終成果。

AI 不會在遊玩時即時產生個案內容，也不會處理真實個案資料。本作品中的 AI 是開發工具，不是替玩家或社工做出專業決策的系統。
