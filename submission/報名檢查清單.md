# 2026 三好 AI 競賽報名檢查清單

官方目前公告的線上報名與作品上傳截止日為 2026 年 11 月 30 日。社會組每隊 1 至 5 人，類別為 AI 數位應用實作類。報名前仍應再次查看官網公告與系統欄位。

## 已完成的檔案與素材

- [x] 可執行的競賽版本機程式。
- [x] 原版與競賽版差異文件 `COMPETITION_CHANGES.md`。
- [x] 作品說明書 Markdown 草稿 `submission/作品說明書.md`。
- [x] 作品說明書 Word 草稿 `submission/作品說明書.docx`，完成後需填入正式網址並核對參賽者資料欄位。
- [x] 三分鐘實際 Demo 影片腳本 `submission/三分鐘示範影片腳本.md`。
- [x] 報名系統精簡文字 `submission/報名文字.md`。
- [x] 測試報告 `TEST_REPORT.md`。
- [x] Chrome 桌機、決策、結算與觸控橫向測試截圖，僅供開發驗證，不取代官方要求的 Demo 影片。

## 仍需參賽者親自準備

- [ ] 報名系統要求的參賽者姓名、聯絡方式及其他個人資料。
- [ ] 身分證正反面影本，或外國國籍證明文件。請只上傳至官方報名系統，不要放入公開 GitHub 或聊天。
- [ ] 若系統針對社會組仍顯示學生證或在學證明欄位，先確認是否為條件式欄位；不要上傳不適用或多餘證件。
- [ ] 參賽切結書：下載官方最新版本，由所有必要簽署人閱讀並簽名後上傳。
- [ ] 依腳本錄製約三分鐘的真實遊戲 Demo，完成剪輯、旁白、字幕及匿名檢查。
- [ ] 將影片上傳至官方接受的位置或影音平台，依系統要求設定可供評審觀看的權限。

## 正式網址與部署

- [ ] 完成 GitHub Pages 部署。
- [ ] 使用未登入或無痕視窗開啟正式網址，確認首頁、三關、決策、支援、結算與重試均可用。
- [ ] 確認評審不需帳號、密碼或特殊權限；若部署方式改為需登入，必須在報名系統提供測試資訊。
- [ ] 將同一個已驗證網址填入作品說明書、報名文字與報名系統。
- [ ] 在 2026 年 12 月 1 日至 12 月 15 日評審期間維持網址可用。

## 影片匿名檢查

- [ ] 影片不出現參賽者人像、姓名、暱稱、學校、工作單位、個人 Logo 或指導者資訊。
- [ ] 不顯示 GitHub 帳號、瀏覽器帳號頭像、書籤、通知、檔案路徑或開發工具。
- [ ] 旁白不自我介紹身分或單位。
- [ ] 影片以真實遊戲操作為主，不用簡報或概念動畫取代 Demo。
- [ ] 片長不超過官方規定的三分鐘。

## 官方系統最後步驟

- [ ] 填寫線上報名表，確認僅報名社會組 AI 數位應用實作類。
- [ ] 上傳作品說明書。
- [ ] 上傳或填入三分鐘作品介紹影片。
- [ ] 上傳完成簽名的參賽切結書。
- [ ] 上傳官方要求且適用的身分證明文件。
- [ ] 檢查所有附件可開啟、網址可操作、影片可播放。
- [ ] 送出前保存畫面或下載報名摘要；送出後確認系統顯示完成或收到確認通知。

## 資格與風險提醒

- 原版已公開。競賽版已加入決策、有限支援與教育性結算等核心玩法變更，但主辦單位是否認定為非形式微調，仍以資格審查結果為準。
- 作品以 AI 協助開發，不代表遊戲本身提供即時 AI 服務；說明書應維持這項區分。
- 本次測試沒有外部使用者研究或專家審查資料，報名內容不得自行增加此類成效數據。
- 官方網站搜尋未發現可公開下載的作品說明書固定範本；目前草稿依官網列出的九項必備內容排序。報名前若系統提供新範本，應把既有內容移入最新範本。
